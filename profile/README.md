# Console Labs

**Building the future with blockchain.** &nbsp;·&nbsp; [console.so](https://console.so)

Console Labs builds crypto-native tools that make on-chain finance feel as
simple as sending a message. Our products live where communities already are:
Discord, Telegram, and the web, serving hundreds of servers.

## Products

### 🍡 Mochi
A crypto bot for Discord and Telegram. Tip and send tokens, track wallets and
prices, and run community rewards, powered by **Mochi Pay**, an in-app wallet
that lets anyone transact across chains without leaving chat.

- [mochi-ui](https://github.com/consolelabs/mochi-ui): accessible React UI library for web3 apps
- [mochi.js](https://github.com/consolelabs/mochi.js): Mochi monorepo and SDKs
- [mochi-go-sdk](https://github.com/consolelabs/mochi-go-sdk): Go SDK
- [mochi-web](https://github.com/consolelabs/mochi-web): Mochi website

### 🤖 Tono
A Discord assistant that pairs live on-chain data with an LLM, so communities
can ask questions about tokens and markets in plain language.

### 🧊 ICY
A BTC ⇄ ICY swap and treasury system. The ICY token is live on Base and Polygon.
